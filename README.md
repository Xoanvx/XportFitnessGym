# 🏋️‍♂️ XportFitnessGym - Sistema de Gestión de Gimnasio

Sistema web integral para la administración y control operativo de un gimnasio. Permite gestionar clientes, membresías, personal, inventario de productos y finanzas (ingresos/gastos).

---

## 🛠️ Tecnologías y Arquitectura

| Capa / Recurso | Tecnología / Herramienta |
| :--- | :--- |
| **Backend** | Java (Servlets, MVC, DAO, DTO, Facade Pattern) |
| **Frontend** | JSP, JSTL, HTML5, CSS3, JavaScript |
| **Base de Datos** | Microsoft SQL Server (Transact-SQL / Procedimientos Almacenados) |
| **Conector JDBC** | MSSQL JDBC Driver |
| **IDE / Build** | Apache NetBeans / Apache Ant |
| **Servidor Web** | Apache Tomcat |

---

## 📌 Módulos del Sistema

| Módulo | Descripción |
| :--- | :--- |
| **Autenticación** | Control de acceso y roles de usuario (Login/Seguridad). |
| **Gestión de Clientes / Socios** | Registro, edición y consulta del padrón de clientes. |
| **Membresías** | Asignación y control de planes/suscripciones vigentes. |
| **Personal** | Administración de empleados, instructores y áreas asignadas. |
| **Catálogo y Almacén** | Control de productos, marcas, categorías y stock del gimnasio. |
| **Finanzas / Gastos** | Dashboard de control de egresos y balance operativo. |

---

## 🚀 Requisitos Previos

- **JDK 11** o superior.
- **Apache NetBeans IDE**.
- **Apache Tomcat 9/10**.
- **SQL Server** instalado y activo.
